Les Private Banda Aceh

Catat tentor, orang tua, dan sesi — honor & invoice terhitung otomatis, tersimpan di laptop ini, bisa dipakai offline
siap
Data tersimpan otomatis di browser laptop ini (bukan di internet) sehingga bisa dipakai offline. Buka file ini langsung lewat browser (bukan dari dalam pratinjau chat) agar penyimpanan berjalan sempurna, dan unduh cadangan secara berkala di tab "Cadangan Data" agar data tidak hilang jika cache browser dibersihkan. Kapasitasnya cukup untuk ratusan tentor dan orang tua sekaligus.
